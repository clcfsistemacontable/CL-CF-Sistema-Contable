# CL&CF — Sistema Contable | V1

Primera versión de interfaz funcional y prototipo multiempresa.

## Archivos
- `index.html` — aplicación
- `style.css` — diseño
- `script.js` — lógica y almacenamiento local
- `logo.jpg` — logotipo proporcionado

## Acceso demo
- Usuario: `admin`
- Contraseña: `CL&CF2026`

## Incluye en V1
- Inicio de sesión de demostración
- Crear y seleccionar empresas
- Gestión contable por empresa
- Datos de empresa: nombre, NIT, tipo, fechas, dirección, teléfono, correo y web
- Plan de cuentas: alta manual, importación CSV y exportación CSV
- Comprobantes con validación Debe = Haber
- Estructura de Libro Diario, Mayor, Balance de comprobación y Ajustes
- Estados financieros y Notas (estructura inicial)
- Módulos base: Bancos, Inventarios, Activos fijos, Intangibles, CxC y CxP
- NC 1–14, NIC y NIIF como biblioteca/estructura inicial
- Registro de UFV y tipos de cambio por fecha
- Reportes e impresión

## Importante
Esta V1 es un prototipo frontend. Los datos se guardan en `localStorage` del navegador y la autenticación demo no es seguridad real. Para una versión productiva se debe incorporar backend, base de datos, autenticación segura, permisos y copias de seguridad.
